# 炉石收藏分解助手

基于本地截图和 OCR 的 Windows 桌面工具，可按职业扫描收藏并自动选择符合规则的普通卡和金色卡。

## 功能

- 一次扫描所选职业的所有页，识别职业边界并停止。
- 可选“全部分解”或“只分解多余的”；传说当前版本留1张，其他留2张，普通与金色分别计算。
- 只有可分解且制作价格、稀有度可确认的普通/金色版本才会自动选中；异画、钻石及无法确认的版本保留。
- 扫描后切换模式无需重扫，可双击卡牌取消选择。
- 执行前一次总确认，指定的套牌同名卡不足提示自动确认；其他未知画面停止。
- F8停止，失焦或游戏窗口尺寸变化时停止。

## 运行源码

需要 Windows x64、Python 3.13。安装依赖后直接运行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

首次使用 RapidOCR 可能下载模型。本仓库不包含依赖运行库、模型、个人扫描缓存或运行日志。

游戏打开中文“我的收藏”，关闭详情与弹窗，选择职业和模式，点击“扫描整个职业”，在倒计时内切回游戏。扫描结束后返回助手检查清单，点击“开始分解”，确认后再次切回游戏。

## 适配和限制

- 按中文、16:9完整窗口适配，实测2560×1440；最低1280×720。其他布局可能停止或跳过。
- 当前支持11职业，中立暂不支持，因为缺少可靠的收藏末页判断。
- 本机适配使用反向原生滚轮映射；程序会检查每次实际页码变化，不符合预期时停止。
- 动画金卡可能因严格卡面比对被保守跳过。名称OCR可能有误，执行同时核对卡面、卡框及数量。
- 实机只读扫描及定位核验已测试，未用真实卡牌测试不可逆分解。指定警告的确认逻辑通过截图和模拟点击测试，未在真实分解中触发。
- 缺少真实钻石详情测试样本，保护采用无法确认即保留的准入规则。

分解不可撤销，请先使用“仅检查（不分解）”。运行时保持游戏前台，不移动或缩放窗口。

## 测试

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

`launch.py` 是原本离线包入口，要求同目录附带 runtime；直接运行源码使用 `app.py`。
